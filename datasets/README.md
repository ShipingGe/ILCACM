Put the activitynet-1.3 dataset here.

The annotations can be easily find on the Internet.

The CLIP features for the ActivityNet-1.3 dataset used in our experiments are extracted using openai/clip-vit-base-patch16.

You can access the features via the following link: [Google Drive](https://drive.google.com/file/d/1u5dLBNY-5GMIEEtZ4B0lLicWp3EdF_W4/view?usp=sharing).

The CLIP features for the ViTT and YouCook2 datasets are obtained from [VidChapters](https://github.com/antoyang/VidChapters).
